# Source Registry

The only file in the wiki that contains filesystem paths. Raw sources live elsewhere on this
computer, organized the user's way — never moved, copied, renamed, or edited. Wiki pages cite
sources by ID (`[[S001]]`); when a file moves, only this registry changes. IDs are append-only
and never reused. History lines are never deleted.
